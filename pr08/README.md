# ПР-8. Взаимные блокировки

## Цель

Реализовать алгоритм банкира, обнаружение цикла в wait-for graph, безопасные блокировки и три решения задачи философов.

## Банкир

```bash
python3 banker.py bank1.txt
printf 'P1 1 0 2\n' | python3 banker.py bank1.txt
printf 'P1 1 0 2\n' | python3 banker.py bank2.txt
```

Для `bank1.txt`: `SAFE`, последовательность `P1 P3 P4 P2 P0`; запрос `P1 [1,0,2]` — `GRANT`. Для `bank2.txt` тот же запрос — `DENY`, состояние откатывается.

## Детектор

```bash
python3 detector.py wait.log
```

Контрольный вывод: `DEADLOCK: P1 -> P2 -> P1`. DFS ищет цикл в графе ожидания ресурсов.

## TrackedLock

```bash
python3 tracked_lock.py
```

Наивный сценарий в обратном порядке вызывает `DeadlockDetected` вместо зависания; единый порядок захвата завершается успешно.

## Философы

```bash
python3 philosophers.py naive
python3 philosophers.py ordered
python3 philosophers.py waiter
```

`naive` намеренно зависает примерно на 10 секунд — это ожидаемая демонстрация deadlock. `ordered` и `waiter` выводят `OK`, каждый из пяти философов ест 20 раз.

## Вывод

Банкир выдаёт ресурс только если после выдачи остаётся безопасная последовательность. Детектор находит уже возникший цикл ожидания. `TrackedLock` предотвращает опасный захват. Упорядочивание ресурсов устраняет круговое ожидание, официант ограничивает число одновременно соревнующихся философов.

**Четыре условия deadlock:** взаимное исключение, удержание и ожидание, отсутствие принудительного отбора, круговое ожидание.

**Почему упорядочивание помогает?** Если все захватывают ресурсы в одном глобальном порядке, цикл зависимостей невозможен.
